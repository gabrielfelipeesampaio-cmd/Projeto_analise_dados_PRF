> Projeto de análise exploratória e preditiva de acidentes em rodovias federais brasileiras.

### ⚠️ IMPORTANTE: Sobre os dados

Este repositório **NÃO contém os dados brutos da PRF** por limitações técnicas do GitHub.

**Por que?**
- O dataset completo de acidentes (2024-2025) ultrapassa **1GB** descompactado
- O GitHub bloqueia arquivos maiores que 100MB e repositórios com mais de 1GB
- Os arquivos `.csv` e `.zip` estão listados no `.gitignore` para evitar travamento do `index.lock`

Para testar o notebook `projeto_prf.ipynb`, você **precisa baixar os dados oficiais manualmente**.
